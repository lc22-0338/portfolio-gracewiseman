Introductory Biomedical Imaging Textbook Website

As part of a team of 5, I developed a textbook website for the course "Introductory Biomedical Imaging" at Lewis & Clark College. The website was built using HTML, CSS, and JavaScript, and is hosted on GitHub Pages. The website includes interactive simulations, course materials, and resources for students and teachers to learn about biomedical imaging techniques.

This project was a part of a CS488 Software Development course. This project was a great oppurtinity to learn to work with clients and not only code and design, but also learn how to manage a project with a team. We followed the extreme programming software development process, which included weekly meetings with our client, biweekly sprints, and regular code reviews. This project was a great learning experience and I am proud of the final product that we delivered to our client.

Simulation Editing and Maintenance

As part of a team, I edited and maintained the simulations for the "Introductory Biomedical Imaging" textbook website. The simulations include interactive visualizations of biomedical imaging techniques, such as MRI and CT scans. The simulations were built using vpython, a Python library for 3D visualizations. Thiis project was an oppurtinity to work with preexisting code and learn how to adapt and improve on a project that is already in development. My responsibilities included debugging and fixing issues with the simulations, as well as adding new features and improving the user experience. This project was a great oppurtunity to learn about simulation development and maintenance, as well as working with a team to manage and improve a project over time.
